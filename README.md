# Portfolio - Lages Yoann

Personal portfolio website showcasing my projects and skills as a Software Engineering student at Holberton School.

## 🌐 Live Demo

[View Portfolio](https://yo13038.github.io/portfolio_0.2/)

## ✨ Features

- **Bilingual Support** - English/French with persistent language selection
- **Interactive Hero Animation** - Click-to-enter zoom animation through the "A" in YOANN
- **Responsive Design** - Works on desktop and mobile devices
- **Project Showcase** - Four featured projects with descriptions and links
- **Contact Section** - Direct email link
- **Social Links** - GitHub and LinkedIn integration

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Custom animations, flexbox/grid layouts, responsive design
- **Vanilla JavaScript** - Language switching, zoom animation, localStorage persistence
- **SVG** - Scalable icons for social links and language flags
